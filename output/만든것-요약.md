# 만든 것 요약 — 엔트레씨 QA 체크리스트 자동 생성 파이프라인

**한 줄 요약: 기획서(.md) 한 장을 넣으면, 섹션별 테스트 케이스 설계 + 빠진 엣지케이스 자동 보완 + P0/P1/P2 점수화 + 출시 가부(릴리즈 게이트) 판정까지 한 번의 Skill 실행으로 만드는 재현 가능한 QA 파이프라인입니다.**

- **속도**: PM·개발자가 겸임으로 스프린트마다 손으로 쓰던 QA 점검표 작성을, 스킬 체인 한 번 실행으로 대체합니다. v1 기획서(섹션 6개·항목 17개) 기준 **테스트 케이스 53건 + 커버리지 리포트 + 출시 판정**이 명령 한 줄(`/spec-to-qa`)로 나옵니다.

- **완전성**: 기획서엔 "정상 동작"만 적혀 있고 예외·실패·폴백 흐름은 빠져 있습니다. 이 공백을 규칙엔진으로 메워, v1 기준 **엣지케이스 27건(전량 출처=AI추가)** 을 빈상태·권한·네트워크·경계값·AI폴백 5유형으로 자동 보완합니다. "매번 빠지는 케이스"를 감이 아니라 **키워드 대입으로 기계 도출**합니다.

- **판단력**: "뭐부터 막지?"를 감으로 정하던 우선순위를 **100점 점수식**(서비스중단 50 + 영향범위 30 + 가역성 20)으로 정식화하고, 점수가 못 잡는 브랜드 리스크는 **도메인 승격 규칙 6종**으로 보완했습니다. v1 53건 전수 대입 → **53/53 재현 일치**로 검증했습니다.

- **실행력**: Challenge 산출물은 케이스 나열에 그치지 않고, **3-tier 릴리즈 게이트**(🔴 미해결 P0>0 보류 / 🟡 P0=0·P1≤2 조건부 / 🟢 출시 가능)로 출시 가부를 기계 판정하고 **테스트 실행 우선순위 플랜 2건**(P0 전량 → 이탈·글로벌 P1군)까지 포함해, PM·QA가 추가 회의 없이 바로 착수할 수 있게 설계했습니다.

- **재현성**: 새 기획서 CSV만 갈아 끼우면 동일한 **Skill 체인(구조분석 → 케이스설계 → 생성 → 자가점검 → 릴리즈판단)** 이 같은 품질로 다시 돌아갑니다. 성격이 완전히 다른 기획서 **4종**(AI·결제·CRUD·예약)으로 실증했습니다.
