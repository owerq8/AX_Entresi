## 1. 구독 플랜 및 결제

무료 사용자가 유료 플랜(Petbbi Plus)을 조회하고 결제 수단을 등록해 구독을 시작하는 기능.

### 1-1. 구독 플랜 조회

- 설정 화면의 "Petbbi Plus" 진입 시 월간/연간 플랜 2종을 카드 형태로 표시
- 월간 플랜: 4,900원/월, 연간 플랜: 39,000원/년(약 17% 할인)
- 각 플랜 카드에는 혜택 목록(AI 캐릭터 재생성 1일 10회, 광고 제거, 커뮤니티 뱃지)이 함께 표시됨
- "구독하기" 버튼 클릭 시 결제 수단 등록 화면으로 이동

### 1-2. 결제 수단 등록

- 신용/체크카드 또는 애플페이·구글페이 중 선택하여 등록
- 카드 등록 시 카드번호·유효기간·CVC 입력, 계정당 최대 3개까지 카드 등록 가능
- 등록된 카드는 마스킹 처리되어 결제 수단 목록에 표시됨(예: "1234-****-****-5678")
- 기본 결제 수단 1개를 지정할 수 있음

### 1-3. 결제 실행

- 선택한 플랜과 결제 수단을 확인 후 "결제하기" 버튼 클릭 시 결제 진행
- 결제 진행 중 로딩 화면 표시, 평균 처리 시간 3~5초
- 결제 완료 시 완료 화면과 함께 구독 시작일·다음 결제일이 표시됨
- 결제 완료 즉시 계정에 Plus 혜택(재생성 한도 상향 등)이 반영됨

## 2. 구독 관리

이미 구독 중인 사용자가 구독 상태를 확인하고 갱신·해지·환불을 처리하는 기능.

### 2-1. 구독 갱신

- 구독은 만료일에 등록된 기본 결제 수단으로 자동 갱신됨
- 갱신 3일 전 "구독이 곧 갱신됩니다" 알림 발송
- 갱신 완료 시 다음 결제일이 자동으로 갱신 주기만큼 연장됨

### 2-2. 구독 해지

- 설정 > 구독 관리 화면에서 "구독 해지" 버튼으로 해지 신청
- 해지 신청 시점부터 자동 갱신은 중단되지만, 이미 결제한 현재 구독 기간이 끝나는 날까지는 Plus 혜택 유지
- 해지 완료 화면에 Plus 혜택 종료 예정일이 표시됨

### 2-3. 환불 신청

- 결제일로부터 7일 이내, 서비스 미사용(재생성 0회 사용) 시 전액 환불 신청 가능
- 환불 신청은 고객센터 문의 화면에서 결제 내역을 선택해 접수
- 환불 승인 시 3~5영업일 내 결제 수단으로 환불 처리되며, 환불 완료 알림 발송
