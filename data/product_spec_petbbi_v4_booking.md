**제품명**: Petbbi(펫삐) — 펫 서비스 예약(Care Booking) 확장 기능
**작성일**: 2026-07-01
**작성자**: (주)엔트레씨 프로덕트팀
**버전**: 4.0
**대상 플랫폼**: iOS / Android 모바일 앱

> 본 문서는 사용자가 앱에서 반려동물 미용·병원 등 제휴 업체를 검색하고 방문 일정을 예약·관리하는 확장 기능의 명세서입니다. 각 기능은 "정상 동작" 기준으로 기술되어 있으며, QA 팀은 이 문서를 입력으로 받아 테스트 케이스를 설계합니다.

## 1. 업체 검색 및 예약

사용자가 주변 제휴 업체를 찾아 원하는 시간대에 방문을 예약하는 기능.

### 1-1. 업체 검색

- 현재 위치를 기준으로 반경 5km 이내의 제휴 업체를 지도와 목록으로 표시
- 업종(미용/병원/호텔), 별점, 거리순으로 정렬 및 필터 적용 가능
- 업체 카드에는 상호명, 대표 사진, 별점(5점 만점), 영업시간이 표시됨
- 검색어(업체명·지역명)로 직접 검색 가능

### 1-2. 예약 시간 선택

- 업체 상세 화면에서 원하는 서비스 항목과 방문 날짜·시간대를 선택
- 예약 가능한 시간대만 활성화되어 표시되며, 마감된 시간대는 비활성화됨
- 예약은 최소 방문 2시간 전까지 가능하며, 최대 30일 이후까지 예약 가능
- 반려동물 프로필(1마리)을 선택해 예약에 연결

### 1-3. 예약 확정

- 선택한 업체·서비스·시간·반려동물을 확인 후 "예약 확정" 버튼 클릭
- 확정 시 예약 완료 화면과 함께 예약번호가 발급됨
- 예약 완료 즉시 "예약 내역" 탭에 추가되고, 방문 1일 전 리마인더 알림이 예약됨

---

## 2. 예약 관리

확정된 예약을 조회하고 변경·취소하는 기능.

### 2-1. 예약 내역 조회

- "예약 내역" 탭에서 예정된 예약과 지난 예약을 구분해 목록으로 표시
- 각 예약 카드에는 업체명, 서비스, 방문 일시, 예약 상태(예약완료/방문완료/취소)가 표시됨
- 예약 카드 클릭 시 상세 화면으로 이동

### 2-2. 예약 변경·취소

- 예약 상세 화면에서 방문 날짜·시간대를 변경하거나 예약을 취소할 수 있음
- 변경·취소는 방문 24시간 전까지만 가능하며, 이후에는 업체에 직접 연락하도록 안내됨
- 취소 완료 시 취소 확인 화면이 표시되고 예약 상태가 "취소"로 갱신됨

### 2-3. 방문 후 리뷰

- 방문 완료 상태의 예약에 대해 별점(5점 만점)과 후기(자유 텍스트, 최대 500자)를 작성 가능
- 리뷰 작성 시 사진 최대 3장 첨부 가능
- 작성된 리뷰는 해당 업체 상세 화면에 노출되며, 사용자당 예약 1건에 리뷰 1개만 작성 가능
