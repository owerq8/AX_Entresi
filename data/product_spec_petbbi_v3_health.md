# Petbbi(펫삐) 기능 명세서 v3.0 — 건강 기록 확장

**제품명**: Petbbi(펫삐) — 펫 건강 기록(Health Log) 확장 기능
**작성일**: 2026-07-01
**작성자**: (주)엔트레씨 프로덕트팀
**버전**: 3.0
**대상 플랫폼**: iOS / Android 모바일 앱

> 본 문서는 반려동물의 체중·급여·병원방문 등 건강 데이터를 기록하고 리포트로 확인·공유하는 확장 기능의 명세서입니다. 각 기능은 "정상 동작" 기준으로 기술되어 있으며, QA 팀은 이 문서를 입력으로 받아 테스트 케이스를 설계합니다.

---

## 1. 건강 기록 입력

반려동물의 체중·급여량과 병원 방문 이력을 기록하는 기능.

### 1-1. 체중·급여 기록

- 프로필 화면의 "건강 기록" 탭에서 "기록 추가" 클릭 → 체중(kg, 소수점 1자리)과 급여량(g) 입력
- 하루 1회 기록 가능하며, 이미 기록한 날짜를 다시 선택하면 기존 값을 수정하는 형태로 동작
- 기록 완료 시 체중 변화 추이가 꺾은선 그래프로 즉시 갱신되어 표시됨

### 1-2. 병원 방문 기록

- 방문일, 병원명, 진료 내용(자유 텍스트, 최대 300자), 진료비를 입력해 기록
- 진료 관련 사진(영수증·소견서 등) 최대 5장 첨부 가능
- 기록 완료 시 "건강 기록" 탭의 타임라인에 날짜순으로 추가됨

---

## 2. 건강 리포트

축적된 건강 기록을 바탕으로 리포트를 생성하고 필요 시 외부(동물병원 등)에 공유하는 기능.

### 2-1. 리포트 자동 생성

- 최근 30일간의 체중 추이·급여 기록·병원 방문 이력을 요약한 리포트를 매주 월요일 자동 생성
- 리포트에는 체중 변화 그래프, 방문 이력 목록, 평균 급여량이 포함됨
- "건강 리포트" 탭에서 주차별로 과거 리포트를 조회 가능

### 2-2. 보호자 공유

- 리포트 화면에서 "공유" 버튼 클릭 시 조회 전용 웹 링크가 생성됨
- 생성된 링크는 7일간 유효하며, 링크를 받은 사람은 로그인 없이 리포트를 볼 수 있음
- 링크를 통해 PDF로 다운로드하거나 카카오톡·이메일로 바로 전송 가능
